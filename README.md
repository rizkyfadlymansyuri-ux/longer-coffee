# Longer Coffee ☕

**Longer Coffee** is a web-based coffee ordering system designed to simplify the process of browsing coffee products and placing orders online.

## Project Overview

This project is developed as part of the *Rekayasa Perangkat Lunak* / *Software Engineering* coursework.

The system aims to provide a convenient ordering experience for customers and support basic coffee shop operations.

## Planned Features

- User registration and login
- Coffee product catalog
- Product categories
- Shopping cart
- Order management
- Order history
- Payment status management
- Admin management of products and orders

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: To be determined
- Database: To be determined
